# Interactive Wright–Fisher Explorer

一个用于学习群体遗传学 Wright–Fisher 模型的交互式可视化工具。

通过有限种群随机抽样，观察等位基因频率的波动、固定与丢失。当前 v0.1 实现经典二倍体、单个位点、双等位基因、中性、恒定种群大小的模型。

详细科学定义见 [项目规格](WF_visualization_SPEC_v0.1.md)，代码边界见 [架构说明](docs/architecture.md)。

## 运行

开发需要 Node.js 22.12+（推荐 Node 24）与 npm；使用 nvm 时可先执行 `nvm use`。

```bash
npm ci
npm run dev
```

打开终端打印的本地地址。模拟在浏览器中运行，不需要后端。

```bash
npm test          # 科学模型、模拟与界面测试
npm run build    # TypeScript 检查与生产构建
npm run preview  # 预览生产构建
```

生产文件位于 `dist/`，可部署至静态站点。源代码包含 TypeScript/TSX，不能直接用 Python 静态服务器运行；如使用 Python 预览，须先构建再运行 `python3 -m http.server --directory dist`。

## 使用

1. 设置二倍体个体数 N、初始 A 拷贝数 X₀ 与代数 T。频率滑块按一个拷贝递增，p₀ = X₀ / (2N)。
2. 设置轨迹数 R（1–100，默认 20），点击“运行模拟”或在页面非交互区域按一次空格。长按不重复触发，输入框、按钮和折叠组件保留原有键盘行为。
3. 每次运行自动生成随机种子，各条轨迹使用不同的伪随机流。按截至 T 的吸收状态着色：丢失（Loss）红色，固定（Fixation）绿色，未吸收（Segregating）灰色。默认第 1 条加粗加深，可用下拉框选择其他轨迹，并通过指针或世代滑块检查其计数。
4. 比较不同 N 时，手动调整 X₀ 以保持相同 p₀。改变 N 默认保留 X₀；超出新范围时必须重新选择。
5. 展开参数或模型解释，查看生物学假设和数学推导；理论默认隐藏。

改变任何实验参数均取消正在运行的实验并清除旧结果，下一次运行创建新实验。固定/丢失后轨迹继续保持在边界直至 T，并报告首次到达的代数（包括第 0 代）。

## 科学与计算约定

- 下一代 A 拷贝数为 `Binomial(2N, Xₜ/(2N))`；不添加额外噪声，也不采用正态近似。
- 内核采用整数拷贝数；频率由计数派生。坐标轴始终覆盖 0–1，线段只连接离散世代，不表示连续时间演化。
- 使用 `mulberry32-v1` 伪随机序列和独立 Bernoulli 求和抽样。复现依赖相同参数、种子、模型与随机算法版本；用途为教学模拟。
- 当前运行上限：`1 ≤ N ≤ 2000`、`1 ≤ T ≤ 2000`、`2NT ≤ 2,000,000`。这些是浏览器计算限制，不是生物学假设。
- 种子由浏览器自动生成，不提供手动设置。批次结果保留种子，模拟层支持程序化复现。参数验证先于计算执行。
- 多轨迹在各重复之间让出主线程，并显示进度；上述工作量上限按每条轨迹计算，总工作量最多为单条的 R 倍。
- 汇总报告截至 T 的固定、丢失和未吸收计数。有限观察窗口内的固定比例不等于最终固定概率。
- 统计测试使用固定种子、理论小种群转移概率和预定义统计容差，不要求随机样本精确等于理论期望。

## 范围

当前支持 1–100 条独立轨迹和重复运行。不包含选择、突变、迁移、重组、种群历史或 backward-time coalescent；这些扩展必须先定义各自状态、数学过程及理论解释。

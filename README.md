# Interactive Wright–Fisher Explorer

通过模拟，观察自然选择、突变和随机漂变如何改变种群中的等位基因频率。

**[打开网站](https://sky-05d75.github.io/WF_visualization/)**

1. 设置种群大小、初始频率、模拟代数和轨迹数（1–100）。
2. 按需开启自然选择或突变，调整对应参数。
3. 点击“运行模拟”，或在非输入区域按空格。每次运行都会产生新的随机轨迹。
4. 选择一条轨迹突出显示，用图下滑块查看各代数据。展开参数旁的解释可了解含义。

曲线颜色表示最后一代的状态：**红色为 A 丢失，绿色为 A 固定，灰色为两种等位基因共存**。有突变时，固定或丢失可能只是暂时的。

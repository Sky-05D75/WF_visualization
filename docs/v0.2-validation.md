# v0.2 本地验收

本页记录 v0.2 的科学验收场景与本地检查方法。

## 启动

```bash
nvm use
npm run dev -- --port 5174 --strictPort
```

访问 http://127.0.0.1:5174/WF_visualization/ 。如服务已经运行，直接访问即可。

## 科学定义补充

- 本版参数域为 s>−1、0≤h≤1、0≤μ,ν≤1。这是规格未明确部分的实施约定；排除零适合度与超/欠显性，确保平均适合度严格为正。
- 随机交配给出选择前的期望基因型频率，不要求每条有限种群轨迹的实际基因型计数恰好符合 Hardy–Weinberg 比例。
- 选择为基因型贡献加权，突变为概率转换，最后仅进行一次二项抽样。选择与突变不交换顺序。
- μ+ν>0 且不含选择时，确定性平衡为 ν/(μ+ν)。0<μ+ν<2 时趋向平衡；μ+ν>1 时交替趋近；μ=ν=1 时翻转。有限种群仍有随机波动。
- ν>0 解除 p=0 的吸收性，μ>0 解除 p=1 的吸收性。两者对边界的作用不可颠倒，也不能把一次未离开边界解释为永久吸收。
- 颜色统一描述末代状态：红色 A 丢失、绿色 A 固定、灰色多态。与 v0.1 在无突变情形完全一致；突变存在时可能出现先到达边界再返回内部的轨迹。

## 自动检查

执行 `npm test` 与 `npm run build`。

测试包括：

1. N=100、p₀=0.5 的一代均值 0.5 与方差 0.00125。
2. 相同初始频率下，N=20 相对 N=1000 在固定观察窗口内具有更大的跨轨迹方差与更高的吸收比例（不混同条件方差，也不把未吸收时间当成吸收时间）。
3. 正负选择的一代均值方向与理论方差；稀有 A 在 h=0、h=1 下的差异。
4. 选择–突变组合的小种群完整转移分布与每代抽样次数。
5. 突变单独作用的恢复趋势、双边界离开与单向突变的吸收边界。
6. 关闭模块或所有系数为零时，与原中性单代函数生成的参考轨迹逐点一致。
7. 无效参数、冻结参数快照、独立开关、末代状态着色、公式渲染以及原多轨迹/快捷键回归。

统计验收使用固定种子和预定义误差容限，不要求每条随机轨迹符合均值趋势。

## 手动检查建议

| 场景 | 参数 | 检查 |
| --- | --- | --- |
| 中性回归 | 两个开关关闭；N=100，X₀=100，T=200，R=20 | 原多轨迹、突出轨迹、空格运行、重置仍可用 |
| 有利选择 | 开启 Selection；s=0.1，h=0.5，R=100 | 多数轨迹上升；逐代读数中 pₛ>pₜ（内部频率） |
| 有害选择 | s=−0.1，其余相同 | pₛ<pₜ；漂变仍可能使单次抽样上升 |
| 显性效应 | X₀=20（p₀=0.1），s=0.1；比较 h=0 与 h=1 | 初始 pₛ 的提升在 h=1 时更大 |
| 边界可离开 | 选择关闭，突变开启；X₀=0，μ=0.02，ν=0.02 | A 可以重新出现；首次边界与吸收分开描述 |
| 极端翻转 | 选择关闭，μ=ν=1，X₀=0，T=3，R=1 | 频率依次 0、1、0、1；末代绿色，无永久吸收 |
| 单向突变 | 选择关闭，μ=0，ν=1，X₀=0 | 一代到达 p=1 后永久吸收；初始 p=0 不吸收 |
| 输入与开关 | 开启选择并输入 s=−1，再关闭选择 | 开启时阻止运行；关闭后无效的隐藏值不影响运行 |
| 理论面板 | 分别展开选择、突变、生命周期 | 默认折叠；公式、方向、条件均值方差与当前过程匹配 |

真实浏览器自动验收目前受环境缺少 Chromium 系统依赖（libnspr4、libnss3、libnssutil3、libxkbcommon）限制；界面回归使用 jsdom。视觉效果和真实浏览器键盘交互需在本地预览中检验。
